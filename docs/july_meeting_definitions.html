Formal Mathematical Definitions

A unified notation for utterance information, contextual uncertainty, Bayes information, production effort, reference generators, and the statistical estimands used to study communicative efficiency.

Current implemented definitionsLogarithms base 2Information in bits
Scope

This page distinguishes four quantities that are conceptually related but mathematically different: target-utterance information, context-only uncertainty, sampled response-space uncertainty, and the legacy and corrected Bayes-derived scores. The notation below follows the computations used in the present analysis pipeline.

01 · Observation level

Units and notation

For child-utterance observation i, let ci(k) denote the preceding caretaker context at window k, and let ui=(xi1,…,xiTi) denote the target child utterance represented as scoring-model tokens.

iOne target-utterance observation.
k ∈ {0,1,2,3}Context window: none, or the most recent one, two, or three caretaker utterances.
xitThe tth tokenizer token of the target utterance.
TiNumber of evaluated target tokenizer tokens; not an orthographic word count.
pθThe common causal language model used to score observed and generated strings.
EiqProduction effort for unit q: words, morphemes, syllables, or phonemes.
Units. All logarithms on this page are base 2 unless explicitly marked ln. Surprisal and entropy are therefore measured in bits.

02 · Observed target

Target surprisal and utterance information

Token surprisal

sit(k) = −log2 pθ(xit ∣ ci(k), xi,<t)
(1)

Terms. pθ is the scorer probability; xi,<t is the already observed target prefix. Higher surprisal means that the observed token was less predictable. Log-softmax outputs in natural units are divided by ln 2.

Total utterance information

Iθ(k)(ui) = ∑t=1Ti sit(k) = −log2 ∏t=1Ti pθ(xit ∣ ci(k), xi,<t)
(2)

Terms. This is sum_bits. The product is the causal probability of the target sequence under the scorer.

Target-only accounting. Context tokens condition the predictions but never enter the target sum. Only tokenizer tokens whose character offsets overlap the target span are evaluated.

Mean information per evaluated token

Ii,tok(k) = Iθ(k)(ui) / Ti,   Ti > 0
(3)

Terms. This is mean_bits_per_token. It is descriptive; the primary fixed-effort models retain total information as the outcome.

Information gained from context

Gi(k) = Iθ(0)(ui) − Iθ(k)(ui)
(4)

Terms. Positive Gi(k) means the specified caretaker context made the observed utterance more predictable than the no-context score; a negative value means it increased surprisal.

03 · Prompt state

Context-only next-token uncertainty

Let Vθ be the scorer tokenizer vocabulary. The target utterance is not shown when this feature is computed.

Hnext(ci(k)) = −∑v∈Vθ pθ(v∣ci(k)) log2 pθ(v∣ci(k))
(5)

Terms. v ranges over every possible next tokenizer token. Higher entropy means the model distributes probability over more alternatives.

pmax(c) = maxv∈Vθ pθ(v∣c),    Imax(c) = −log2 pmax(c)
(6)
Interpretive boundary. This is the uncertainty of one next token after the context. It is neither the surprisal of the observed child response nor the entropy of complete possible responses.

04 · Sampled response space

Full-response entropy

For context ci, suppose Mi valid sampled responses collapse to Ki distinct normalized response types. If type j appears nij times,

p̂ij = nij / Mi,    ∑j=1Ki nij = Mi
(7)
Ĥresp(ci) = −∑j=1Ki p̂ij log2 p̂ij
(8)

Terms. This plug-in estimator is the Shannon entropy of the empirical distribution over complete normalized response strings.

ĤMM(ci) = Ĥresp(ci) + (Ki−1) / (2Mi ln 2)
(9)

Terms. The Miller–Madow term reduces the leading small-sample downward bias. The primary feature uses valid normalized responses; invalid or empty generations are audited separately.

05 · Prior and context evidence

Bayes identity and corrected candidate-set score

p(ui∣ci) = p(ci∣ui) p(ui) / p(ci)
(10)

Taking negative base-2 logarithms converts Bayes' rule into an additive information decomposition:

IBayes(ui∣ci) = −log2p(ui) − log2p(ci∣ui) + log2p(ci)
(11)

Terms. The three terms are utterance prior information, context-given-utterance information, and the context-evidence normalizer.

The archived first pilot estimated the first two terms:

ĨBayes(ui,ci) = Iprior(ui) + Icontext∣utterance(ci∣ui)
(12)

Terms. Iprior(u)=−log2p̂(u) and Icontext∣utterance(c∣u)=−log2p̂(c∣u).

IBayes(ui∣ci) = ĨBayes(ui,ci) + log2p(ci)
(13)
Normalization caveat — archived pilot only. The legacy bayes_bits_unnormalized value omits log2p(c), was trained on overlapping PBM rows, and used a reverse trigram whose candidate conditioning reached only the first context token. It is not exact posterior surprisal and should not support substantive claims.

Corrected cross-fitted score

The corrected PBM estimator holds out the entire evaluated corpus and trains additively by age. Its whole-utterance/whole-context contrastive term estimates a context likelihood ratio:

Êi ≈ log2[ p(ci∣ui,ai) / p(ci∣ai) ]
(14a)
Si(u) = log2p̂(u∣ai) + Ê(ci,u,ai)
(14b)

For the available real/random/unigram/bigram/trigram set Ai,

qAi(u∣ci,ai) = 2Si(u) / ∑v∈Ai2Si(v),   IAi=−log2qAi
(14c)

Terms. candidate_set_probability is normalized only over the supplied candidate set. candidate_set_bayes_bits is its surprisal. Neither is a posterior over every possible utterance. The contrastive Ê is learned from matched versus shuffled pairs and is not a literal neural sequence likelihood.

Cross-fitted word prior

p(w∣h) = [N(h,w)+α] / [N(h)+α|V|],    α=0.1
(14d)

Terms. h is word history, N denotes non-held-out training counts, and |V| includes an explicit unknown-token state. The order is three with progressive backoff and end-of-sequence. A target age bin uses only its own and preceding bins.

06 · Production cost

Production effort and information density

Eiq = ∑ℓ=1Li eq(wiℓ),    q ∈ {{word, morpheme, syllable, phoneme}}
(15)
Effort unitImplemented contribution eq(w)
WordsOne per orthographic word token; punctuation-only material is excluded.
MorphemesA surface-form base count plus recognized clitic and suffix contributions.
SyllablesDictionary pronunciation count when available, with a syllabification fallback.
PhonemesDictionary pronunciation count when available, with a grapheme-to-phoneme fallback.
Diq(k) = Iθ(k)(ui) / Eiq,    Eiq > 0
(16)

Terms. Information density is bits per measured effort unit. It is a descriptive normalization, not the primary regression definition of efficiency.

Expected effort in a sampled response distribution

Eiqgen = (1/Mi) ∑m=1Mi Eq(rim)
sE,iqgen = √[ ∑m=1Mi(Eq(rim)−Eiqgen)2 / (Mi−1) ]
(17)

Terms. rim is sampled response m. The standard deviation uses the sample denominator Mi−1.

Riq=Eiq−Eiqgen,   Ziq=Riq/sE,iqgen,   Piq=[#(Egen<Eiq)+½#(Egen=Eiq)]/Mi
(18)

Terms. R is the real-minus-expected residual, Z is defined when generated standard deviation is positive, and P is the tie-aware midrank percentile.

07 · Counterfactual controls

Developmentally constrained reference generators

For additive age bin b, the training sample contains the current bin and every earlier bin. Let Vb be its word vocabulary.

quniform,b(w)=1/|Vb|,    quni,b(w)=Nb(w)/∑v∈VbNb(v)
(19)
qn,b(w∣h)=Nb(h,w)/Nb(h)
(20)

Terms. Trigrams back off to bigrams and then unigrams when a history is unavailable. The initial generated word is conditioned on the tail of the caretaker context.

qφ(ui∣ci)=∏ℓ=1Liqφ(wiℓ∣ci,wi,<ℓ),    ℒ(φ)=−∑i,ℓln qφ(wiℓ∣ci,wi,<ℓ)
(21)

Terms. This is the LSTM generator factorization and training cross-entropy. Generator probabilities are not reported as Mistral information: all generated and observed strings are subsequently scored with the common pθ.

Matched developmental information. Random, unigram, bigram, trigram, and additive LSTM controls learn only from the current age bin and earlier bins. Matched-length variants generate the same orthographic word count as the paired real utterance.
ΔIi = Iθ(bi∣ci) − Iθ(ui∣ci)
(22)

Terms. bi is a paired generated control. Positive ΔIi means the control is more surprising than the observed child utterance under the same scorer.

08 · Inferential target

Regression estimands for communicative efficiency

Let ai be age in months, Ei selected target effort, Pi preceding caretaker effort, Hi context-only next-token entropy, and j(i) child identity. Continuous predictors are mean-centered: zic=zi−z.

Current supervisor model family (23)
ModelImplemented linear predictorScientific role
M1Ii=β0+βaaic+βEEic+εiAge and target effort, pooling children.
M2M1 + γj(i)Adds a fixed intercept for each child.
M3M2 + βaEaicEicAllows the age slope to vary with effort.
M4M3 + βPPic+βHHicAdds both current context controls.

Ii is total target surprisal; γj(i) is the child fixed intercept; εi is residual variation. Models use ordinary least squares with uncertainty clustered by child.

Coefficient meanings

βaAge slope at mean effort (bits per month), conditional on included controls.
βEEffort slope at mean age (bits per additional effort unit).
βaEChange in the age slope per additional effort unit, equivalently change in the effort slope per month.
βP, βHAdjusted associations of caretaker amount and prompt-state uncertainty with target information.

Fixed-effort developmental estimand

m(a;e,p,h,j) = E[Ii ∣ ai=a, Ei=e, Pi=p, Hi=h, j(i)=j]
(24a)
∂m/∂a = βa + βaEEic
(24b)

Terms. The headline question is whether expected target information changes with age while measured production effort and contextual controls are held fixed. A negative slope means less surprisal at the same measured effort; it is not by itself a claim about communicative success or a universal scalar efficiency score.

Response-space model

Yi=β0+βaaic+βRHMM,ic+βaRaicHMM,ic+βGEi,wordsgen,c+βCCic+βNHnext,ic+γj(i)+εi
(25)

Terms. Yi is a real-versus-generated relative-effort outcome, Ei,wordsgen is expected generated response word count, Ci is context word count, and Hnext,i adjusts for prompt-state uncertainty. Continuous outcomes use OLS; binary outcomes use a binomial generalized linear model. This is a separate estimand from target surprisal.

09 · Descriptive complexity

Secondary complexity summaries

TTR = V/N,    MLUwords = (total word tokens)/(number of utterances)
(26)

Terms. N is the word-token count and V the distinct word-type count. TTR is sample-size sensitive and remains descriptive unless token budgets are controlled. MLU is average utterance length, not an information measure.

10 · Reporting rule

Interpretation boundary

Observed target information asks how surprising the produced utterance was. Next-token context entropy asks how uncertain the model was before seeing a response. Full-response entropy asks how diverse a sampled set of complete possible responses was. Corrected candidate-set Bayes surprisal combines an out-of-corpus age-conditioned prior with contrastive context evidence and normalizes only over the supplied five-way candidate set. Information density divides information by measured effort, whereas the main developmental estimand compares predicted information at fixed effort.

These quantities can support a common theory of communicative efficiency, but they remain mathematically distinct and should retain separate names in the paper.
