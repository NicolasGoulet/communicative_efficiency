# Paired TinyDialogues–Mistral PBM Child Trajectories

These overlays use exactly matched child/session/age trajectory cells. Scores are standardized separately within each scorer because the models have different tokenizers and calibration scales. Points are observed cells; straight lines are descriptive weighted slopes, not interpolation through missing ages.
