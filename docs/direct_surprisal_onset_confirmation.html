Interpretation

An onset is not the first nominally significant coefficient. It is the first adequately supported post-reference bin whose upper simultaneous band is below zero and for which every later adequately supported bin also remains below zero. If the confirmation result is not_established, the prior PBM statement that the first row-level decrease appears by 24–29 months remains exploratory and must not be promoted as a replicated developmental onset.

These bands use the frozen lexical-word effort definition. Full-79 validated morpheme, syllable, and phoneme controls are not yet available, so this report does not satisfy that separate alternative-effort validation requirement.
